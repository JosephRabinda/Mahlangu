SIBONGILE SANDY MAHLANGU — 20TH BIRTHDAY WEBSITE
====================================================

This version has been reorganised into clean, readable parts.

PAGES
-----
1. index.html
   - Elegant birthday countdown page.
   - Responsive navigation.
   - Three-photo background collage.
   - Countdown to 10 October.
   - Birthday celebration message appears when the countdown reaches zero.

2. wishes.html
   - Full birthday wishes page.
   - Personal letter.
   - 20 birthday wishes.
   - Difficult-days reminder.
   - New chapter message.
   - Five-photo gallery.
   - Three-video memory section.
   - Final birthday message.

STYLING
-------
Both HTML pages use:
    css/style.css

The stylesheet is shared by both pages so the website keeps one consistent
design system while remaining responsive on desktop, tablet and mobile.

JAVASCRIPT
----------
js/script.js handles:
    - Mobile navigation
    - Scroll reveal animations
    - Floating particles
    - Birthday countdown

ADDING YOUR MEDIA
-----------------
Place the following files inside images/:

    background-1.jpg
    background-2.jpg
    background-3.jpg

    memory-1.jpg
    memory-2.jpg
    memory-3.jpg
    memory-4.jpg
    memory-5.jpg

Optional video poster images:

    video-poster-1.jpg
    video-poster-2.jpg
    video-poster-3.jpg

Place these videos inside videos/:

    memory-1.mp4
    memory-2.mp4
    memory-3.mp4

Optional browser icon:

    sibongile-icon.png

HOW TO OPEN
-----------
Extract the ZIP folder and double-click:

    index.html

No server or database is required.

IMPORTANT
---------
The code is intentionally written going down in clear sections instead of
being compressed into single lines. This makes it easier to study, edit and
present as a web-development project.
